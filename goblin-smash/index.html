Goblin Smash — Assistance

English below

Un problème, une question, une idée ? Écrivez à goblinsmash.app@gmail.com. Indiquez votre modèle d'iPhone et la version du jeu (écrite en haut à gauche du menu).

J'ai changé de téléphone ou réinstallé le jeu : mon achat a disparu

Menu → Réglages → « Restaurer mon achat », puis « Restaurer ». Utilisez le même identifiant Apple que pour l'achat. Rien n'est facturé une deuxième fois.

Ma progression a disparu

La progression est enregistrée uniquement sur votre appareil : elle est effacée si vous supprimez le jeu. L'achat, lui, se récupère toujours avec « Restaurer ».

Comment couper le son ou les statistiques ?

Menu → Réglages.

Goblin Smash — Support

A problem, a question, an idea? Write to goblinsmash.app@gmail.com. Please mention your iPhone model and the game version (top left of the menu).

I changed phones or reinstalled the game: my purchase is gone

Menu → Settings (Réglages) → "Restaurer mon achat", then "Restaurer". Use the same Apple ID as for the purchase. You will not be charged again.

My progress is gone

Progress is stored only on your device: it is deleted if you delete the game. The purchase can always be recovered with "Restore".
